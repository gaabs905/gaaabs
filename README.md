# PetVida — Landing Page

Landing page responsiva criada para o projeto de vendas pet.

## Estrutura
- `index.html` — página e copy
- `styles.css` — design responsivo/mobile-first
- `script.js` — interações
- `assets/` — pasta reservada para imagens e mídia

## Executar
Abra `index.html` no navegador ou publique com GitHub Pages/Vercel/Netlify.

## Antes de vender
A oferta atual é demonstrativa. Substitua produto, preço, depoimentos, logística, políticas e o link de checkout pelos dados reais da operação.

## Checkout
No arquivo `index.html`, o botão usa `data-checkout`. Após definir o checkout real, substitua o `href="#" ` pelo link correto e remova o alerta correspondente de `script.js`.
